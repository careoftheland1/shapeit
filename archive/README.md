# Build It interface snapshots

`buildit-original-ui-2026-08-20.tar.gz` contains the complete original Build It
interface immediately before the alternate Shelter-style interface became the
default. It includes the original application component, entry point, global
styles, public assets, configuration, and package manifests.

SHA-256: `0d2a136449bdaecf121955db44851e7f7e51c9fc4129b851d5c6080ec3766692`

Restore into an empty directory with:

```bash
tar -xzf buildit-original-ui-2026-08-20.tar.gz
```
